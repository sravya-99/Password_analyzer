# Password_analyzer

A Python-based application that analyzes the strength of passwords using standard security criteria. It evaluates password complexity, provides security recommendations, estimates password entropy, and generates strong passwords to help users create more secure credentials.

## Features

* Analyze password strength
* Check password length
* Detect uppercase and lowercase letters
* Detect numbers and special characters
* Calculate password strength score
* Classify passwords as Weak, Moderate, or Strong
* Suggest improvements for weak passwords
* Generate secure random passwords
* Calculate password entropy

## Technologies Used

* Python
* Regular Expressions (`re`)
* Random
* String
* Math
* IPyWidgets
* Jupyter Notebook

## How to Run

```bash
pip install ipywidgets
jupyter notebook
```

Open the notebook and run all the cells to start analyzing passwords.
